# Publishing on CurseForge (owner steps)

CurseForge's terms do not allow automated access, so these are done by hand, once.

1. Sign in at https://www.curseforge.com/ (an Overwolf account, in your own name, 18+).
2. For each of the four packs, go to https://authors.curseforge.com/#/projects/create/minecraft and choose **Mods**. Copy the fields from the pack's `LISTING.md` (name, summary, categories, license, source URL, description), upload `pack.png` as the logo, then upload the `.jar` from `dist/` as the file with loaders Fabric, Quilt, NeoForge and game versions 1.21 to 1.21.11 and 26.1 to 26.3. Submit for review.
3. When a project is approved, open https://authors.curseforge.com/#/reward-store and accept the Rewards Program terms. Points arrive monthly once a project passes CurseForge's popularity threshold; 1 point = US$0.05, cash-out through Tremendous/PayPal from the reward store.

Do not use AI-generated screenshots. If you add screenshots, take them in game.

Modrinth: not submitted. Its content rules do not allow publicly listing projects that are primarily AI-written.
